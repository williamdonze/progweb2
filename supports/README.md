# Les supports du cours

Dépose ici les fichiers du cours, tels que tu les as reçus : slides, PDF, énoncés de TP, consignes de projet, examens blancs, pages web enregistrées (« Enregistrer sous… → Page web complète », ou un zip).

- **Depuis GitHub** : ouvre ce dossier, puis **Add file → Upload files**, glisse les fichiers, **Commit changes**.
- **Ensuite**, dans une session Claude Code sur ce dépôt : **`/nouveau-cours`** (la première fois) ou **`/ajouter-supports`** (pour la suite du cours). Claude repère les fichiers qu'il n'a pas encore traités (registre : `docs/cours/index.md`), te propose ce qu'il en tire, et attend ton accord avant d'écrire.

Un nom de fichier parlant aide (`semaine-05-sessions.pdf`, `tp3-enonce.pdf`). Si le dépôt est public, ces fichiers le sont aussi : vérifie que ton prof est d'accord, ou garde le dépôt privé.
